# Vinayak — Personal Portfolio

The finished static website is in [`outputs/vinayak-portfolio`](./outputs/vinayak-portfolio). It uses semantic HTML, CSS, and vanilla JavaScript, with no build step or third-party runtime dependency.

To preview it locally, run `node work/serve.cjs` from this workspace root. Run `node work/checks.cjs` for configuration, navigation, accessibility-related, and interaction checks.
